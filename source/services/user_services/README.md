## User service có authentication và authortication

Chạy service thủ công bằng lệnh
```bash
npm install
npm run dev
```

Test service nhanh:
```bash
npm test
```

Build lại proto thì generate lại:
```bash
npm run proto:generate
```

**Dockerfile** đang được để tạm, chưa được build thử để biết có thể chạy được không.
