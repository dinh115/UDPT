# Hospital Management Using Microservices

## Project Overview

This project was developed as part of the **Distributed Application** course at the **University of Science, Vietnam National University - Ho Chi Minh City**. It leverages **microservice architecture** to build a hospital management application, covering the entire process from system design to implementation.

## Deployment Instructions
The application has not been deployed to a public server.
To run the application locally:
1. Execute the docker-compose file.

2. Start the API Gateway in Docker.

3. Access the application via localhost.

## Key Features
- Appointment scheduling and management

- Prescription management and issuance

- Medical record management

- Notifications and statistical reports
For more details, please refer to the project report.
